เครื่องช่างภาพของคุณ = ที่เก็บรูปทั้งหมด เปิดไว้ตลอดงาน

1 · เซิร์ฟเวอร์บนเครื่องนี้

รูปทั้งหมดอยู่บนดิสก์เครื่องนี้ (ไม่มีการอัปโหลดไปเก็บที่อื่น) ชี้โฟลเดอร์รูป เช่น tether folder ของ Lightroom แล้วกดเริ่ม

ยังไม่เริ่ม

2 · เชื่อมกับระบบกลาง (hub)

ใส่ hub ของระบบเรา — hub จะดึงภาพจากเครื่องนี้แบบ realtime ไปให้แขกดู แต่ไม่เก็บภาพบน hub เด็ดขาด แขกได้ลิงก์สวย ๆ hub/e/ชื่องาน

หรือใช้บัญชี hub
ยังไม่เชื่อมต่อ

◉ หลักการ: ดิสก์เครื่องนี้คือที่เก็บหลัก — hub เป็นแค่ทางผ่านของข้อมูล ไม่มีไฟล์ภาพถูกบันทึกบนเซิร์ฟเวอร์ภายนอกแม้แต่ไฟล์เดียว ปิดหน้าต่างนี้เมื่อเชื่อมต่อแล้วก็ได้ ระบบทำงานต่อเบื้องหลัง
